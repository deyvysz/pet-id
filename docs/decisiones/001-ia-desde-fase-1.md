# 001. Reconocimiento por foto desde la fase 1

Fecha: noviembre de 2026. Decidió: Deyvys.

El documento de la Dra. De Castro dejaba la IA para una fase posterior. Se decidió incluirla desde la fase 1.

Por qué: las fotos guiadas se piden en el registro. Si el reconocimiento llega después, habría que pedir fotos de nuevo a todos los usuarios ya registrados, y muchos no volverían. Con la IA desde el inicio, cada registro deja vectores listos para buscar y el conjunto de datos crece desde el primer día.
