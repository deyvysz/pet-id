# 002. Stack

Fecha: noviembre de 2026. Decidió: Deyvys.

Por qué: una sola base de datos guarda fichas y vectores, sin una base vectorial aparte. La web responsiva cubre móvil y escritorio sin publicar en tiendas en la fase 1.
