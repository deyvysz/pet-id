# 003. Licencias de modelos

Fecha: noviembre de 2026. Decidió: Deyvys.

Se usa DINOv2 ViT-B/14 (Apache 2.0) para los vectores. Para detectar la mascota: DETR, OWL-ViT o Grounding DINO.

No se usan Ultralytics YOLO (AGPL, obliga a abrir el código del servicio) ni MegaDescriptor (CC BY-NC, prohíbe uso comercial). Petnow, Petco Love Lost y PetFace se revisaron como referencia; ninguno ofrece una API abierta que se pueda integrar sin contrato.
